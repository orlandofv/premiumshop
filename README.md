# PremiumShop – Responsive E-Commerce HTML Template

PremiumShop is a modern responsive e-commerce HTML template designed for
online stores, product marketplaces, and commercial storefronts.

It includes clean UI components, Bootstrap integration, and multiple
store layout variants.

Author: orlandofv  
Version: 1.0

---

## Template Variants

PremiumShop includes three versions:

Standard  
Basic storefront pages.

Professional  
Extended version with additional system pages.

Plus  
Full storefront + Admin Dashboard UI.

---

## Key Features

• Bootstrap 5 responsive layout  
• Product catalog pages  
• Product detail pages  
• Shopping cart interface  
• Checkout UI flow  
• Wishlist system  
• Customer profile page  
• Category navigation  
• Admin dashboard UI (Plus version)  
• Mobile-first design  
• SEO-friendly HTML  
• Easy integration with backend frameworks
