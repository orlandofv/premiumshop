Recommended Demo Structure

How to organize your hosting.

Upload one landing page at the root, then place each template demo in its own folder.

1
Create the subdomain

Set up premiumshop.samtics.com in your hosting panel and point it to its own document root.

2
Upload the folders

Place standard, professional, and plus inside the subdomain root.

3
Add this landing page

Save this file as index.html in the subdomain root so buyers see the premium demo selector first.

4
Test all paths

Verify that CSS, JS, images, and page links work correctly in each demo folder.
